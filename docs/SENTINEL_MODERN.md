# Sentinel Modern in PvPSentinel

PvPSentinel `0.3.1.23` uses the published `MarshalTitan.SentinelCore.UI` `0.3.1` library from SentinelCore `v0.3.1.0` (commit `300703b360a58fb4b73bf7675d31fe8cab4614cd`). The pinned UI and generic Core NuGet packages are included under `.packages/SentinelCore/v0.3.1.0` so builds and the installed plugin do not require another Sentinel plugin. The UI package has SHA-256 `e1a9ce4e1ce36042c0fcd53f4c23874d918640be10eef16c21f1cd436c6ba747`.

The Appearance section offers Classic and Sentinel Modern. Pre-theme configurations migrated to Classic; existing `ConfigurationTheme` choices remain saved (`0` or `1`). New installations start in Classic. No gameplay values, window identifiers, or persisted Dalamud window positions change. Invalid saved theme values fall back to Classic.

Modern configuration uses Core's unified application shell, blue/violet/teal ambience, custom header, Font Awesome icon rail, responsive settings rows, switches, glass card, and status pill. Seven existing pages map directly to the rail with no secondary categories. The selected heading and settings share the right content pane, and navigation never stacks. Reduced motion follows Dalamud's UI setting. The established ImGui window ID and `FirstUseEver` setting preserve saved positions and larger sizes. Classic retains the native title bar and all settings; Modern uses the Core close/minimize/expand controls and header dragging. Minimize keeps the themed header, status, page label and restore button visible; expanded dimensions and the compact choice persist without changing the window ID. The Development window retains its dense diagnostic workflow and plugin-specific threat, behavior, and state colours. Gameplay behavior, provider coordination, and queue state are unchanged.

To verify in game, select Modern in Appearance, resize the configuration window at several UI scales, use mouse/keyboard/controller navigation, drag the header, collapse and reopen with `/pvpsentinel config`, close and reopen through Dalamud, enable reduced motion, restart, and use the single **Switch to Classic** action. Check settings, emergency STOP, and saved window position both outside and inside Frontline. The `repo.json` in this repository is the authoritative child manifest; release notification asks the central Sentinel generator to reconcile it.
